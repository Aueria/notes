## Purpose 

Implements direct hardware access to the True Random Number Generator (TRNG) on the STM32F405, bypassing HAL to generate random numbers via register manipulation.
## Steps

### Part 1: Direct Hardware Access for TRNG

1. Created TRNG library:
    
    - Created folder TRNG in project.
        
    - Added to include path: Right-clicked project, selected Add/Remove Include Path.
        
    - Added to source location: Navigated to Project > Properties > C/C++ General > Paths and Symbols > Source Location, added TRNG.
        
    - Created trng.h:
        
        ```c
        #ifndef TRNG_H_
        #define TRNG_H_
        
        #ifdef DEBUG
        #include <stdio.h>
        #define TRNG_DBG(...) printf(__VA_ARGS__)
        #else
        #define TRNG_DBG(...)
        #endif
        
        #define TRNG_BASE_ADDR 0x50060800
        #define TRNG_CR (*((volatile uint32_t *)(TRNG_BASE_ADDR + 0x00)))
        #define TRNG_SR (*((volatile uint32_t *)(TRNG_BASE_ADDR + 0x04)))
        #define TRNG_DR (*((volatile uint32_t *)(TRNG_BASE_ADDR + 0x08)))
        
        #define TRNG_CR_RNGEN (1U << 2)
        #define TRNG_CR_IE (1U << 3)
        #define TRNG_SR_DRDY (1U << 0)
        
        void trng_init(void);
        uint32_t trng_get(void);
        
        #endif /* TRNG_H_ */
        ```
        
    - Created trng.c:
        
        ```c
        #include "main.h"
        #include "trng.h"
        
        static uint32_t last_rng = 0;
        
        void trng_init(void) {
            TRNG_DBG("TRNG init\n");
            TRNG_CR |= TRNG_CR_RNGEN;
            TRNG_DBG("CR: 0x%08lX, SR: 0x%08lX\n", TRNG_CR, TRNG_SR);
        }
        
        uint32_t trng_get(void) {
            while ((TRNG_SR & TRNG_SR_DRDY) == 0 || TRNG_DR == last_rng) {
                // Wait for new data
            }
            TRNG_DBG("CR: 0x%08lX, SR: 0x%08lX, DR: 0x%08lX\n", TRNG_CR, TRNG_SR, TRNG_DR);
            last_rng = TRNG_DR;
            return last_rng;
        }
        ```
        
2. Updated main code:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        #include "trng.h"
        ```
        
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t next_tick = 1000;
        uint32_t loop_count = 0;
        ```
        
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Starting TRNG\n");
        trng_init();
        trng_get(); // Discard first value as per manual
        ```
        
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now >= next_tick) {
            uint32_t random = trng_get();
            printf("Random: %lu\n", random);
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            next_tick = now + 1000;
        }
        ```
        
3. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed serial output showing TRNG initialization (CR = 0x4, SR = 0x1), random numbers every second.
        
    - Noted: Lacked error checking for TRNG faults.
        

## Observations

- TRNG generated random numbers via direct register access (0x50060800).
    
- Serial output confirmed CR (0x4), SR (0x1), and random values.
    
- Loop counts showed ~21M loops/sec with -Og.
    
- Bypassing HAL provided low-level control but needs error handling.
    

## Troubleshooting

- No TRNG output: Ensured RNG clock enabled in STM32CubeMX.
    
- No UART output: Checked USART1, PA9 to serial RX, 921600 baud.
    
- TRNG hang: Verified TRNG_CR_RNGEN set, checked SR for data ready.
