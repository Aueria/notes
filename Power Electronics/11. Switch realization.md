Our original model uses a SPDT (single-pole double throw) switch. This model is used to show that there are 2 different current paths.

However, in reality, all power semiconductor devices function as SPST (single pole single throw) switches. Therefore, to create a more accurate model, we use two SPST switches instead of a single SPDT switch.

![[Pasted image 20250809185802.png]]

With this new configuration, instead of the two possibilities we have (either position 1 or 2), we have 4 different configurations:

| Switch A | Switch B |
| -------- | -------- |
| On       | Off      |
| Off      | On       |
| On       | On       |
| Off      | Off      |
In this particular example, we cannot short both A and B as this short circuit will draw massive current, which will probably destroy the switches, if not creating huge power losses. Therefore, we have to make sure that this never happens even for a few nanoseconds.

On the other hand, both switches can be open at the same time, which changes the characteristics of the converter. This will be discussed later.

# Quadrants

Using a single-quadrant switch as example:

![[Pasted image 20250809190852.png]]

1. Switch off state voltage: 
It is the voltage applied to the switch (MOSFET) when off (open circuit). 
It is also known as the blocking voltage, which is the voltage that the switch have to block when it is off. 
Usually it is $V_g$ or capacitor voltage. 

2. Switch on state current: 
It is the current flowing through the switch when turned on (short circuit)

In this particular example, we can see that from the graph above, both the switch off state voltage and switch on state current is positive. Therefore, it is called a single-quadrant switch.


In fact, there are other possibilities:

![[Pasted image 20250809191617.png]]

Current bidirectional:
The switch needs to withstand current flowing from both sides. Perhaps at one duty cycle, the current is positive, at another its negative. But it only needs to block positive voltage when its off.

Voltage bidirectional:
The switch needs to block both polarities of voltage when off, but only conducts one polarity of current

Four-quadrant:
The most general case. Blocks voltage of both polarities and conducts current both side

## Single-quadrant switches

There are multiple types:
1. Active switch: Switch state is controlled exclusively by a third terminal (control terminal) i.e. MOSFETS
2. Passive switch: Switch state is controlled by the applied current and/or voltage at terminals 1 and 2. i.e. diodes
3. SCR: A special case — turn-on transition is active, while turn-off transition is passive. (i.e. turns on by a third terminal, but only turn off when reverse biased)
4. Single-quadrant switch: on-state i(t) and off-state v(t) are unipolar.

When solving for the converter, if the intended voltage lies in quadrant 2, we can realize it using a diode

On the other hand, if the current defined is opposite to what this voltage shows, we can se that the diode functions in quadrant 4. If, when we do analysis of the converter, and it lies on the 4th quadrant, we would know we can realize it by placing the diode in the opposite direction.
