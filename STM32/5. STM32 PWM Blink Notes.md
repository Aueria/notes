## Purpose 

Implements hardware-based LED blinking using TIM4 PWM on PB6 (wired to PC13) for the STM32F405, offloading toggle operations from the CPU.
## Steps

### Part 1: Hardware Timer PWM

1. Added UART support:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
2. Added startup and PWM start:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Starting PWM timer\n");
        HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);
        ```
        
3. Added UART and loop counter:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t next_tick = 1000;
        uint32_t loop_count = 0;
        ```
        
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now >= next_tick) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            next_tick = now + 1000;
        }
        ```
        
4. Built and flashed:
    
    - Connected wire from PB6 to PC13 (LED).
        
    - Rebuilt and reflashed.
        
    - Observed LED blinking at 1 Hz (500 ms on/off) via PWM.
        
    - Used oscilloscope to verify 1 Hz, 50% duty cycle.
        
    - Commented out main loop code; LED still blinked, confirming hardware PWM.
        
5. Tested duty cycle:
    
    - Changed Pulse to 1000 (71% duty cycle) in STM32CubeMX, regenerated code.
        
    - Observed wider pulse on oscilloscope, same 1 Hz frequency.
        

## Observations

- LED blinked at 1 Hz via TIM4 PWM on PB6, no CPU code needed.
    
- Serial output showed ~21M loops/sec with -Og optimization.
    
- PWM offloaded blinking to hardware, freeing CPU.
    
- Duty cycle adjustment (e.g., 71%) changed pulse width, not frequency.
    

## Troubleshooting

- LED issues: Verified PB6-PC13 wiring, timer settings (prescaler, period, pulse).
    
- No UART output: Checked USART1, PA9 to serial RX, 921600 baud.
    
- PWM issues: Ensured correct timer channel, polarity.
