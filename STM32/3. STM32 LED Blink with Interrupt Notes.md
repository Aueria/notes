## Purpose 

Extends the non-blocking blink application by adding a button interrupt on PA0 to cycle LED blink speeds (500 ms, 250 ms, 100 ms), demonstrating external interrupt handling.
## Steps

### Part 1: Non-Blocking Blink with Loop Counter

1. Added timing and counter variables:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t last_blink = 0;
        uint32_t last_tick = 0;
        uint32_t loop_count = 0;
        ```
        
2. Added UART support:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
3. Added startup message:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Non-blocking blink starting\n");
        ```
        
4. Added non-blocking code:
    
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now - last_blink >= 500) {
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
            printf("Toggling GPIO - Loop Count: %lu\n", loop_count);
            loop_count = 0;
            last_blink = now;
        }
        if (now - last_tick >= 1000) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            last_tick = now;
        }
        ```
        
        Toggles LED every 500 ms (2 Hz), prints loop counts (~5.2M/sec with -Og).
        
5. Built and flashed:
    
    - Clicked Build (hammer icon).
        
    - Connected ST-Link: SWDIO to PA13, SWCLK to PA14, GND to GND, 3.3V to 3.3V.
        
    - Clicked Run (green play icon).
        
    - Observed LED blinking every 500 ms.
        
    - Serial output showed loop counts (~5.2M loops/sec with -Og optimization).
        

### Part 2: External Interrupt for Button

1. Added interrupt variables:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint8_t button_pressed = 0;
        uint16_t blink_delays[] = {500, 250, 100};
        uint8_t blink_delay_idx = 0;
        ```
        
2. Implemented interrupt callback:
    
    - In USER CODE BEGIN 0, added:
        
        ```c
        void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
            if (GPIO_Pin == BUTTON_Pin) {
                button_pressed = 1;
            }
        }
        ```
        
        Sets flag on button release (rising edge).
        
3. Updated main loop:
    
    - Modified USER CODE BEGIN 3 to:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now - last_blink >= blink_delays[blink_delay_idx]) {
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
            printf("Toggling GPIO - Loop Count: %lu\n", loop_count);
            loop_count = 0;
            last_blink = now;
        }
        if (now - last_tick >= 1000) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            last_tick = now;
        }
        if (button_pressed) {
            blink_delay_idx++;
            if (blink_delay_idx >= sizeof(blink_delays) / sizeof(blink_delays[0])) {
                blink_delay_idx = 0;
            }
            printf("Button pressed - New blink delay: %u ms\n", blink_delays[blink_delay_idx]);
            button_pressed = 0;
        }
        ```
        
        Cycles LED speed (500/250/100 ms) on button press.
        
4. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed LED speed cycling on button press.
        
    - Serial output showed button press messages.
        

## Observations

- LED blinked at 2 Hz (500 ms) initially, cycled to 250 ms and 100 ms on button press.
    
- Serial output showed ~3.17M loops/sec without optimization, ~5.2M with -Og.
    
- Button interrupt triggered on release (rising edge), creating simple UI.
    
- Non-blocking approach allowed multi-tasking (LED toggling, UART printing).
    

## Troubleshooting

- LED issues: Verified PC13 (GPIO_Output, High default), ST-Link connections.
    
- Button issues: Ensured PA0 pull-up, rising edge, NVIC enabled.
    
- No UART output: Checked USART1, PA9 to serial RX, 921600 baud.
    
- Interrupt not triggering: Verified NVIC settings, PA0 wiring.
