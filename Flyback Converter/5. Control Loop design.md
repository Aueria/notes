# Voltage Mode feedback control

There is a 90 phase shift in inductor, another 90 in capacitor

![[Pasted image 20250820172250.png]]

1. Second Order system
2. Phase Shift = 180
3. Type 3 error amp (gives 180 phase boost)
4. Harder to compensate

# Current Mode feedback control

The left part can be modelled as a current source. The inductor can also be modelled as a current source. Combining both current source allows us to simplify the circuit to form one bigger current source.

![[Pasted image 20250820172819.png]]

Combining 2 current source

![[Pasted image 20250820173335.png]]

1. First Order System
2. Phase Shift is 90
3. Simpler to compensate

>[!note
>We will be using current mode as it is easier to compensate for]
