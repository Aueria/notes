# Transformer model

To apply the transformer model, we need one more equation.

## Converter input port

The input current ($i_g$) waveform is shown below:

![[Pasted image 20250803182233.png]]

1. When the switch is connected, $i_g$ and $i_L$ is connected ($i_g$ is current before the inductor and $i_L$ is current after the inductor). Therefore, the current is approximately the same.
2. Since the output of the inductor is a ripple (in steady state), small ripple approximation is used to calculate the input current DC component (average)
3. The output area is then approximated as a rectangle/square, instead of a trapezium

After calculating DC component (avg) of $i_g(t)$, which is simply done by calculating the area in the above picture:
$$
I_g = \frac{1}{T_s} \int_0^{T_s} i_g(t) dt = DI_L
$$
