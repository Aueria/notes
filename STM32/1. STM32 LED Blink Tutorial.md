## Purpose 

Introduces a basic LED blink application on the STM32 Black Pill (STM32F411CE) using STM32CubeIDE, progressing from a blocking delay to a non-blocking approach using `HAL_GetTick()` for multi-tasking.
## Steps

### Part 1: Project Creation

1. Selected File > New > STM32 Project in STM32CubeIDE.
    
2. Chose STM32F411CEU6 (48-pin UFQFPN).
    
3. Named project Black_Pill_Blink, clicked Finish. Opened STM32CubeMX.
    
4. Configured MCU:
    
    - Debug Interface: Navigated to System Core > SYS, set Debug to Serial Wire (PA13 for SWDIO, PA14 for SWCLK), enabled Trace Asynchronous SW for SWO on PB3 (optional).
        
    - LED Pin: Set PC13 to GPIO_Output (LED, active low: low = on, high = off), renamed to LED, set GPIO Output Level to High, used Push-Pull mode (or Open Drain).
        
    - UART (Optional): Navigated to Connectivity > USART1, enabled Asynchronous mode, set baud rate to 921600, noted USART1 uses PA9 (TX), PA10 (RX).
        
    - Clock: Navigated to System Core > RCC, set HSE to Crystal/Ceramic Resonator (25 MHz on PH0/PH1), set input to 25 MHz in Clock Configuration, configured PLL: PLL_M = 12, PLL_N = 96, PLL_P = 2 (100 MHz system clock), ensured timer clocks at 100 MHz.
        
5. Clicked Generate Code.
    

### Part 2: Basic Blink with Blocking Delay

1. Edited main.c in Core/Src/main.c.
    
2. Added UART Redirect (Optional):
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
3. Added Startup Message:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Blink application starting\n");
        ```
        
4. Added Blocking Blink Code:
    
    - In USER CODE BEGIN 3 (inside while(1)), added:
        
        ```c
        HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
        printf("Loop\n");
        HAL_Delay(1000);
        ```
        
        Toggles LED and prints “Loop” every 1000 ms (1 Hz).
        
5. Built and Flashed:
    
    - Clicked Build (hammer icon).
        
    - Connected ST-Link: SWDIO to PA13, SWCLK to PA14, GND to GND, 3.3V to 3.3V.
        
    - Clicked Run (green play icon), accepted default debugger settings.
        
    - LED on PC13 blinked every 1 second.
        
    - If using UART, opened microcom -s 921600 /dev/ttyUSB0, saw “Blink application starting” and “Loop” every second.
        

### Part 3: Non-Blocking Blink

1. Added Timing Variables:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t last_blink = 0;
        uint32_t last_tick = 0;
        ```
        
2. Updated Startup Message:
    
    - Modified USER CODE BEGIN 2 to:
        
        ```c
        printf("Non-blocking blink starting\n");
        ```
        
3. Replaced Blocking Code with Non-Blocking Logic:
    
    - Replaced USER CODE BEGIN 3 with:
        
        ```c
        now = HAL_GetTick();
        if (now - last_blink >= 500) {
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
            printf("Toggling GPIO\n");
            last_blink = now;
        }
        if (now - last_tick >= 1000) {
            printf("Tick\n");
            last_tick = now;
        }
        ```
        
        Toggles LED every 500 ms (2 Hz), prints “Toggling GPIO” every 500 ms and “Tick” every 1000 ms.
        
4. Built and Flashed:
    
    - Rebuilt and reflashed project.
        
    - LED blinked faster (every 500 ms).
        
    - Serial monitor showed:
        
        - “Non-blocking blink starting” on boot.
            
        - “Toggling GPIO” every 500 ms.
            
        - “Tick” every 1000 ms (two “Toggling GPIO” per “Tick”).
            

## Observations

- Blocking version: LED blinks every 1000 ms (1 Hz), serial output shows “Loop” every 1000 ms.
    
- Non-blocking version: LED blinks every 500 ms (2 Hz), serial output shows “Toggling GPIO” every 500 ms, “Tick” every 1000 ms.
    
- Non-blocking approach allows multi-tasking without wasting CPU cycles.
    

## Troubleshooting

- LED not blinking: Verified PC13 configured as GPIO_Output with High default, checked ST-Link connections and board power.
    
- No UART output: Ensured USART1 enabled, PA9 connected to serial adapter’s RX, confirmed baud rate (921600) and correct serial port.
    
- ST-Link issues: Updated firmware if prompted, verified pin connections (SWDIO, SWCLK, GND).
