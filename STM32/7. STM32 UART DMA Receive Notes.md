## Purpose 

Implements UART communication with DMA receive on the STM32F405, using USART2 for transmit and UART4 for receive, with LED pulses to indicate received data, demonstrating efficient data handling.
## Steps

### Part 1: UART Transmit with Loop Counter

1. Added UART support:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        #include <string.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
2. Added variables:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #define BUFFER_SIZE 64
        ```
        
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t next_tick = 1000;
        uint32_t loop_count = 0;
        uint32_t next_tx = 1000;
        uint32_t tx_count = 1;
        char tx_buffer[BUFFER_SIZE];
        char rx_buffer[BUFFER_SIZE];
        uint8_t dma_buffer[BUFFER_SIZE];
        ```
        
3. Added startup message:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Starting UART DMA\n");
        ```
        
4. Added transmit code:
    
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now >= next_tick) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            next_tick = now + 1000;
        }
        if (now >= next_tx) {
            snprintf(tx_buffer, BUFFER_SIZE, "Transmitting message %lu from USART2\n", tx_count);
            printf("%s", tx_buffer);
            HAL_UART_Transmit(&huart2, (uint8_t *)tx_buffer, strlen(tx_buffer) + 1, HAL_MAX_DELAY);
            tx_count++;
            next_tx = now + 1000;
        }
        ```
        
        Transmits string every 1000 ms via USART2 (blocking).
        
5. Built and flashed:
    
    - Clicked Build (hammer icon).
        
    - Connected ST-Link: SWDIO to PA13, SWCLK to PA14, GND to GND, 3.3V to 3.3V.
        
    - Clicked Run (green play icon), accepted default debugger settings.
        
    - Observed serial output showing “Tick” and transmit messages every second (~9M loops/sec due to blocking transmit).
        

### Part 2: UART DMA Receive

1. Started DMA receive:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        HAL_UARTEx_ReceiveToIdle_DMA(&huart4, dma_buffer, BUFFER_SIZE);
        ```
        
        Initiates circular DMA receive on UART4.
        
2. Added DMA callbacks:
    
    - In USER CODE BEGIN 0, added:
        
        ```c
        static uint32_t last_offset = 0;
        static char rx_string[BUFFER_SIZE];
        static uint32_t rx_string_len = 0;
        
        void process_char(uint8_t c) {
            if (c == 0) {
                printf("Received: %s", rx_string);
                rx_string_len = 0;
                rx_string[0] = '\0';
            } else if (rx_string_len < BUFFER_SIZE - 1) {
                strncat(rx_string, (char *)&c, 1);
                rx_string_len++;
            }
        }
        
        void HAL_UARTEx_RxEventCallback(UART_HandleTypeDef *huart, uint16_t Size) {
            if (huart->Instance == UART4) {
                if (Size != last_offset) {
                    for (uint32_t i = last_offset; i != Size; i = (i + 1) % BUFFER_SIZE) {
                        process_char(dma_buffer[i]);
                    }
                    last_offset = Size;
                }
            }
        }
        
        void HAL_UART_ErrorCallback(UART_HandleTypeDef *huart) {
            if (huart->Instance == UART4) {
                printf("UART4 error\n");
                while (1);
            }
        }
        ```
        
        Processes received characters, handles circular buffer wrap-around, prints completed strings.
        
3. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed serial output showing transmitted and received strings (matching due to PA2-PA0 wire).
        
    - Noted: Receive-to-idle DMA triggered on pauses or half/full buffer, processed zero-terminated strings correctly.
        

### Part 3: LED Pulse on Receive

1. Configured timer for LED pulse:
    
    - In STM32CubeMX, navigated to Timers > TIM4, set Clock Source to Internal Clock (APB1 at 84 MHz), set Prescaler to 83 (84 - 1), Counter Period to 29999 (30000 - 1) for 30 ms pulse, enabled Update Event interrupt in NVIC, regenerated code.
        
2. Added LED pin:
    
    - Set PC13 to GPIO_Output, renamed to LED, set High default, Push-Pull mode.
        
3. Added LED pulse code:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint8_t led_flash = 0;
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        void led_flash_start(void) {
            HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_RESET); // LED on (active low)
            HAL_TIM_Base_Start_IT(&htim4);
            led_flash = 1;
        }
        
        void HAL_TIM_PeriodElapsedCallback(TIM_HandleTypeDef *htim) {
            if (htim->Instance == TIM4) {
                HAL_GPIO_WritePin(LED_GPIO_Port, LED_Pin, GPIO_PIN_SET); // LED off
                HAL_TIM_Base_DeInit(&htim4);
                led_flash = 0;
            }
        }
        ```
        
    - In process_char, replaced printf("Received: %s", rx_string) with:
        
        ```c
        led_flash_start();
        ```
        
4. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed LED pulsing for 30 ms on each received string.
        
    - Serial output showed transmit messages; LED replaced receive print.
        

### Part 4: High-Speed UART

1. Increased baud rate:
    
    - In STM32CubeMX, set USART2 and UART4 baud rate to 2625000, regenerated code.
        
2. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed same functionality (transmit/receive, LED pulses) at ~20x faster rate.
        
    - Serial output showed reduced loop counts due to faster transmission, but DMA handled receive efficiently.
        

## Observations

- Initial UART at 115200 baud: ~9M loops/sec due to blocking transmit.
    
- DMA receive with ReceiveToIdle handled strings efficiently, triggered on pauses or buffer events.
    
- LED pulsed for 30 ms on each received string, visible feedback.
    
- High-speed UART (2.625M baud) worked flawlessly with DMA, minimal CPU overhead.
    
- Loop counts dropped slightly at higher baud due to faster transmit.
    

## Troubleshooting

- No UART output: Checked USART1/USART2/UART4, PA9/PA2 to RX, 115200 or 2625000 baud.
    
- No LED pulse: Verified PC13 (GPIO_Output, High default), timer settings (prescaler=83, period=29999).
    
- DMA issues: Ensured DMA stream, circular mode, interrupts enabled.
    
- Receive issues: Verified PA2-PA0 wire, checked ReceiveToIdle callback.
