## Purpose 

Optimizes the non-blocking blink application with button interrupt by simplifying button checks and timing comparisons, improving performance while maintaining LED speed cycling.
## Steps

### Part 1: Non-Blocking Blink with Loop Counter

1. Added variables:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t last_blink = 0;
        uint32_t last_tick = 0;
        uint32_t loop_count = 0;
        uint8_t button_pressed = 0;
        uint16_t blink_delays[] = {500, 250, 100};
        uint8_t blink_delay_idx = 0;
        ```
        
2. Added UART support:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
3. Added interrupt callback:
    
    - In USER CODE BEGIN 0, added:
        
        ```c
        void HAL_GPIO_EXTI_Callback(uint16_t GPIO_Pin) {
            if (GPIO_Pin == BUTTON_Pin) {
                button_pressed = 1;
            }
        }
        ```
        
4. Added startup message:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Non-blocking blink starting\n");
        ```
        
5. Added non-blocking code:
    
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now - last_blink >= blink_delays[blink_delay_idx]) {
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
            printf("Toggling GPIO - Loop Count: %lu\n", loop_count);
            loop_count = 0;
            last_blink = now;
        }
        if (now - last_tick >= 1000) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            last_tick = now;
        }
        if (button_pressed) {
            blink_delay_idx++;
            if (blink_delay_idx >= sizeof(blink_delays) / sizeof(blink_delays[0])) {
                blink_delay_idx = 0;
            }
            printf("Button pressed - New blink delay: %u ms\n", blink_delays[blink_delay_idx]);
            button_pressed = 0;
        }
        ```
        
        Toggles LED at variable intervals, prints loop counts (~5.2M/sec with -Og).
        

### Part 2: Code Optimization

1. Simplified button check:
    
    - Changed if (button_pressed == 1) to:
        
        ```c
        if (button_pressed)
        ```
        
        Removed explicit comparison (~30 loops/sec gain).
        
2. Optimized timing checks:
    
    - Replaced last_blink and last_tick with next_blink and next_tick.
        
    - In USER CODE BEGIN PV, updated:
        
        ```c
        uint32_t now = 0;
        uint32_t next_blink = 500;
        uint32_t next_tick = 1000;
        uint32_t loop_count = 0;
        uint8_t button_pressed = 0;
        uint16_t blink_delays[] = {500, 250, 100};
        uint8_t blink_delay_idx = 0;
        ```
        
    - Modified USER CODE BEGIN 3 to:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now >= next_blink) {
            HAL_GPIO_TogglePin(LED_GPIO_Port, LED_Pin);
            printf("Toggling GPIO - Loop Count: %lu\n", loop_count);
            loop_count = 0;
            next_blink = now + blink_delays[blink_delay_idx];
        }
        if (now >= next_tick) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            next_tick = now + 1000;
        }
        if (button_pressed) {
            blink_delay_idx++;
            if (blink_delay_idx >= sizeof(blink_delays) / sizeof(blink_delays[0])) {
                blink_delay_idx = 0;
            }
            printf("Button pressed - New blink delay: %u ms\n", blink_delays[blink_delay_idx]);
            button_pressed = 0;
        }
        ```
        
        Used direct comparison, moved additions to less frequent blocks.
        
3. Built and flashed:
    
    - Rebuilt and reflashed.
        
    - Observed LED blinking at 500 ms, cycling to 250 ms, 100 ms on button press.
        
    - Serial monitor showed higher loop counts (~10M/sec with -Og).
        

## Observations

- Initial code: ~3.17M loops/sec without optimization, ~5.2M with -Og.
    
- Optimized code: ~10M loops/sec by simplifying comparisons and moving calculations.
    
- Button interrupt cycled LED speeds (500/250/100 ms), maintaining functionality.
    
- Non-blocking approach supported multi-tasking (LED, UART, button).
    

## Troubleshooting

- LED issues: Verified PC13 (GPIO_Output, High default), ST-Link connections.
    
- Button issues: Ensured PA0 pull-up, rising edge, NVIC enabled.
    
- No UART output: Checked USART1, PA9 to serial RX, 921600 baud.
    
- Interrupt issues: Verified NVIC settings, PA0 wiring.
