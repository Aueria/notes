## Purpose 

Implements dynamic LED dimming using TIM4 PWM on PB6 (wired to PC13) for the STM32F405, adjusting duty cycle at 100 Hz for smooth brightness control.
## Steps

### Part 1: Dynamic PWM Dimming

1. Added UART support:
    
    - In USER CODE BEGIN Includes, added:
        
        ```c
        #include <stdio.h>
        ```
        
    - In USER CODE BEGIN 0, added:
        
        ```c
        int __io_putchar(int ch) {
            HAL_UART_Transmit(&huart1, (uint8_t *)&ch, 1, HAL_MAX_DELAY);
            return ch;
        }
        ```
        
2. Added PWM variables:
    
    - In USER CODE BEGIN PV, added:
        
        ```c
        uint32_t now = 0;
        uint32_t next_tick = 1000;
        uint32_t loop_count = 0;
        uint32_t pwm_value = 500;
        int8_t pwm_change = 10;
        uint32_t next_change = 100;
        ```
        
3. Added startup and PWM start:
    
    - In USER CODE BEGIN 2, added:
        
        ```c
        printf("Starting PWM timer\n");
        HAL_TIM_PWM_Start(&htim4, TIM_CHANNEL_1);
        ```
        
4. Added dynamic PWM code:
    
    - In USER CODE BEGIN 3, added:
        
        ```c
        loop_count++;
        now = HAL_GetTick();
        if (now >= next_tick) {
            printf("Tick %lu seconds - Loop Count: %lu\n", (now / 1000), loop_count);
            loop_count = 0;
            next_tick = now + 1000;
        }
        if (now >= next_change) {
            __HAL_TIM_SET_COMPARE(&htim4, TIM_CHANNEL_1, pwm_value);
            pwm_value += pwm_change;
            if (pwm_value >= 1000) {
                pwm_value = 1000;
                pwm_change = -10;
            } else if (pwm_value <= 0) {
                pwm_value = 0;
                pwm_change = 10;
            }
            next_change = now + 10; // Change every 10 ms
            printf("PWM value: %lu\n", pwm_value);
        }
        ```
        
        Adjusts PWM pulse width every 10 ms for dimming.
        
5. Built and flashed:
    
    - Connected wire from PB6 to PC13.
        
    - Rebuilt and reflashed.
        
    - Observed LED dimming up/down at 100 Hz.
        
    - Oscilloscope showed pulse width cycling (1 ms to 9 ms).
        
    - Tested next_change increment at 2 ms for faster dimming.
        
    - Serial monitor showed PWM values and tick counts (~21M loops/sec with -Og).
        

## Observations

- LED dimmed smoothly by cycling PWM duty cycle at 100 Hz.
    
- Oscilloscope confirmed pulse width changes (1 ms to 9 ms).
    
- Serial output showed ~21M loops/sec with -Og.
    
- Polarity set to Low matched active-low LED behavior.
    

## Troubleshooting

- LED issues: Verified PB6-PC13 wiring, timer settings, polarity.
    
- No UART output: Checked USART1, PA9 to serial RX, 921600 baud.
    
- PWM issues: Ensured correct prescaler, period, pulse values.
