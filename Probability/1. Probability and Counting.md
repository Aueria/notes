1. Sample space is the set of all possible outcomes of an experiment
2. An event is a subset of the sample space

# Naive definition of probability:

$P(A) = \frac{\text{Number of favorable outcome}}{\text{Number of possible outcomes}}$
Where P is the probability, A is the event

### Example 1: Coin Flipping

In coin flipping, there are 4 possibilities (H = head, T = tails):

| Result 1 | Result 2 |
| -------- | -------- |
| H        | H        |
| H        | T        |
| T        | H        |
| T        | T        |
Suppose we want to know the probability that both tosses are tails.

There is only one favorable outcome (T, T) and there are 4 total outcomes. Therefore, the probability is $\cfrac{1}{4}$
